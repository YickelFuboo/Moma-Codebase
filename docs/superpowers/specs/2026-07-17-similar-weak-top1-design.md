# similar 弱查询 Top1 增强

日期：2026-07-17  
状态：已实现（弱案 Top1=4/4，avg P=88%；强案保持 100%）

## 目标

弱改写查询正确文件尽量排第 1：Top1 命中 ≥3/4，弱案 avg P≥75%；强案不回退。

## 手段（仅 rerank）

1. 稀有 token 加权：长度≥6 或含 `_` 的标识符，在 content 命中时加分
2. 路径段匹配：query token 与 file_path 路径段/stem 重叠时小幅加分
3. 融合权重微调：略降纯向量、抬高 lexical/稀有/路径

## 非目标

重索引、加长返回列表、改 embedding 模型
